# Equicrew Frontend Add-on

Custom frontend for Home Assistant with Equicrew branding and customizations.

## Features

- eq cube branding (logo, colors, text)
- Green theme (#23935E primary, #38CE7F accent)
- All links point to equicrew.com
- Custom translations

## Installation

This add-on is built automatically via GitHub Actions and published to GHCR.

## Version

Based on Home Assistant 2024.12.0 with Equicrew customizations.
