# Equicrew Frontend Add-on

Custom frontend for Home Assistant with Equicrew branding and customizations.

## Features

- eq cube branding (logo, colors, text)
- Green theme (#23935E primary, #38CE7F accent)
- All links point to equicrew.com
- Custom translations

## Installation

1. Open Home Assistant
2. Go to **Settings** → **Add-ons** → **Add-on Store**
3. Click **⋮** (three dots) → **Repositories**
4. Add: `https://github.com/behindvillager/eq-frontend`
5. Find and install **Equicrew Frontend**
6. Start the add-on
7. Access at `http://<your-ha-ip>:8099`

## Version

Based on Home Assistant 2024.12.0 with Equicrew customizations.
