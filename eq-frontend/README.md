# Equicrew Frontend Add-on

Custom frontend for Home Assistant with Equicrew branding and customizations.

## Features

- eq cube branding (logo, colors, text)
- Green theme (#23935E primary, #38CE7F accent)
- All links point to equicrew.com
- Custom translations

## Installation

Add this repository to your Home Assistant instance:

1. Go to **Settings** → **Add-ons** → **Add-on Store**
2. Click **⋮** (three dots) → **Repositories**
3. Add: `https://github.com/behindvillager/eq-frontend`
4. Install **Equicrew Frontend** from the store
5. Start the add-on
6. Access at `http://<your-ha-ip>:8099`

## Configuration

No configuration needed. The add-on runs nginx on port 8099.

## Version

Based on Home Assistant 2024.12.0 with Equicrew customizations.
