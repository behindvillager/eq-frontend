# Equicrew Home Assistant Add-ons

This repository contains custom Home Assistant add-ons for Equicrew.

## Add-ons

### Equicrew Frontend

Custom Home Assistant frontend with Equicrew branding.

- **Features**: eq cube logo, green theme (#23935E), custom translations
- **Based on**: Home Assistant 2024.12.0
- **Port**: 8099

[Documentation](eq-frontend/README.md)

## Installation

1. Add this repository to Home Assistant:
   - **Settings** → **Add-ons** → **Add-on Store** → **⋮** → **Repositories**
   - Add: `https://github.com/behindvillager/eq-frontend`

2. Install "Equicrew Frontend" from the store

3. Start the add-on and access at `http://<your-ha-ip>:8099`
